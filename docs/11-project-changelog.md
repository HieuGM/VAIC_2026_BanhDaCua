### Added
- **feat(data-api chat BFF) (2026-07-18, commit `de120e2`, nhánh `feat/data-api-chat-bff`):** hiện thực hoá ADR-008 — data-api Spring Boot 3.4.1 (port 8081) làm chat BFF + persistence, JSON blocking (no SSE). Flyway `V10__create_chat_sessions_and_messages.sql` (schema `hospital`, đã apply PG): `chat_sessions` (id UUID PK, created_at/updated_at TIMESTAMPTZ default now(), lang VARCHAR(8), anon_token UUID, expires_at TIMESTAMPTZ, deleted_at TIMESTAMPTZ; index `anon_token`) + `chat_messages` (id BIGSERIAL PK, session_id UUID FK→chat_sessions(id) ON DELETE CASCADE, role VARCHAR(16) CHECK in user/assistant/system, content TEXT NOT NULL, citations JSONB, intent VARCHAR(64), route VARCHAR(64), guardrail_flags JSONB, confidence REAL, created_at TIMESTAMPTZ default now(); index `(session_id, created_at)`). Entity `ChatSession` (UUID id, own timestamps — NOT extend BaseEntity) + `ChatMessage` (extends BaseEntity, `@ManyToOne` ChatSession, jsonb via Hibernate `@JdbcTypeCode(SqlTypes.JSON)`). `ChatService.handleMessage`: resolve/create session → persist user msg FIRST → proxy chatbot → on success persist assistant msg; on `ChatbotUnavailableException` persist fallback assistant msg + return HTTP 200. `ChatbotClient` (RestClient POST `{chatbot}/api/v1/chat`, timeout config) → `ChatbotUnavailableException` on network/timeout/5xx/parse. `ChatController` 3 endpoints: `POST /data/v1/chat` (body `{sessionId?, text, lang?}` → `ChatResponse`); `GET /data/v1/chat/sessions` (PageResponse, filter by `X-Anon-Token` header); `GET /data/v1/chat/sessions/{sessionId}/messages` (PageResponse, ASC by created_at). **No auth** (`anonToken` from header `X-Anon-Token`; if missing/invalid UUID → data-api generates one). **No streaming.** Fallback (chatbot down): HTTP 200, answer = `"Tạm thời không kết nối được tới trợ lý. Vui lòng thử lại."`, `guardrailFlags=["upstream_error"]`, `intent="UNKNOWN"`; user msg vẫn được persist. Validation: `text` `@NotBlank`; `lang` optional defaults `"vi"`. **Deviation from earlier plan:** if `sessionId` provided but NOT found → HTTP **404** (`ChatSessionNotFoundException extends ResourceNotFoundException`), NOT "create new session". `ChatResponse` fields: `sessionId, answer, citations[], confidence, intent, guardrailFlags[], redirection?, needsHandoff, metadata`. Config: `hanoi-heart.chatbot.{base-url (default http://localhost:8000), connect-timeout-ms, read-timeout-ms}` trong `application.yml` + `.env.example` (`CHATBOT_BASE_URL`). Contract data-api↔chatbot VERIFIED khớp `chatbot-service/api/chat_schemas.py`. Tests: 11/11 pass (ChatServiceTest 4 + ChatControllerTest 6 @WebMvcTest + 1) — edge matrix: chat 200+fallback (ASCII + Vietnamese UTF-8), empty text→400, fake sessionId→404, sessions list→200 PageResponse. **Status:** implemented + unit/integration tested locally (data-api side); real-chatbot E2E + browser E2E pending AI team (chatbot chưa run local — Python 3.14 + heavy ML deps); chưa merge `develop`.
